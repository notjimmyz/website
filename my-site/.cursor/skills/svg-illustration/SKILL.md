# SVG Illustration

Use SVG for major illustrated environments.

Prefer:
- simple paths and geometric shapes
- flat pastel fills
- recognizable silhouettes
- layered scene elements
- reusable React SVG components

Break scenes into semantic groups:

- background
- buildings
- landscape
- props
- characters
- interactive elements

Keep individual elements separately addressable so they can animate.

Avoid excessive SVG detail.

The style is soft editorial minimalism with playful nostalgia.
